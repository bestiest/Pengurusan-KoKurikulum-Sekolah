Sistem Pengurusan Kokurikulum & PAJSK

Aplikasi berasaskan web komprehensif bagi pengurusan maklumat murid, penyertaan luar, markah PAJSK, janaan automatik Surat Kebenaran Waris (A4 Landscape), Kejohanan Sukan Tahunan dan Merentas Desa.

Makluman Penting Hos Web

Aplikasi Memerlukan Pelayan Python (FastAPI & SQLite)

GitHub Pages hanya memaparkan fail statik (HTML/CSS). Bagi membolehkan pangkalan data murid, log masuk pengguna, dan simpanan rekod berfungsi, aplikasi ini menggunakan pelayan Python. Anda boleh menjalankannya secara tempatan atau hos secara percuma di Cloud (Render.com).

Hos Online Percuma (Render.com) Cara Jalankan di Komputer Sekolah

Ciri-Ciri Utama Sistem

Pengurusan Maklumat Murid

Penyelarasan kelas tetap (1 UM, 2 UKM, 3 UPM, 4 USM, 5 UTM, 6 UITM), pendaftaran 4 unit wajib, import/eksport Excel serta semakan keahlian bertindih secara automatik.

Janaan Surat Kebenaran Waris

Format rasmi A4 Landscape (sebelah kiri Surat Makluman Sekolah, sebelah kanan Borang Kebenaran Ibu Bapa). Ruangan tandatangan sekolah terbuka untuk cop GPK Ko / Guru Besar.

Penyertaan Luar & PAJSK

Perekodan automatik kontinjen aktiviti luar serentak dengan janaan surat kebenaran, penilaian gred PAJSK mengikut peringkat serta laporan pencapaian individu.

Kejohanan Sukan & R01/R02

Pengurusan pendaftaran acara balapan & padang mengikut rumah sukan, janaan automatik Borang MSSM R01 & R02 (dengan No. Jersi), serta jadual kutipan mata terkini.

Kejohanan Merentas Desa

Perekodan masa pemenang individu (1-15), taburan mata penamat zon 16-50, pengiraan automatik juara rumah sukan dan kawalan keselamatan penghapusan keputusan.

Kawalan Akses & Hak Milik

Perlindungan integriti data: Hanya akaun Admin, Penyelaras, GPK Ko, dan Setiausaha Sukan dibenarkan menghapus laporan, rekod dan maklumat rasmi unit.

Panduan Menjalankan Sistem di Komputer Sekolah (Tempatan)

1

Buka Folder Projek

Buka folder sistem di komputer anda: C:\Antigravity\Sistem Pengurusan Unit Kokurikulum

2

Klik Dwi-Kali Fail `start.bat`

Fail ini akan memulakan pelayan tempatan Uvicorn secara automatik dan memastikan pangkalan data sedia digunakan.

3

Buka Pelayar Web

Buka Google Chrome atau Microsoft Edge dan layari: http://127.0.0.1:8000
